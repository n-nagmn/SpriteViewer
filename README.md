# スプライト番号抽出・管理ツール

スプライトシート（PNG画像）から個々のスプライトを選択し、名前や状態、サイズなどのメタデータを付与して管理・エクスポートするためのGUIツールです。

## 主な機能

- **スプライトシートの読み込み**: PNG形式の画像を読み込み、グリッド表示します。
- **スプライトの自動検出**: 画像内の不透明なピクセルが含まれる16x16領域を自動的に緑色の枠で強調表示します。
- **直感的な選択**: キャンバス上をクリックすることでスプライト番号を取得し、赤い枠で選択範囲を表示します。
- **プレビュー機能**: 選択した範囲を拡大してプレビュー表示します。
- **柔軟なサイズ設定**: 16x16だけでなく、16x32や32x32など、複数のプリセットおよびカスタムサイズに対応しています。
- **データ管理**:
    - キャラクタ名、状態（向きやアクション）を登録。
    - 登録済みスプライトの一覧表示（名前順・番号順ソート）。
    - 登録データの編集・削除。
- **インポート/エクスポート**:
    - 登録したデータをJSON形式で保存。
    - 保存したJSONを読み込んで再編集可能（旧バージョンのデータフォーマットも自動変換して対応）。

## 動作環境

- Python 3.x
- `Pillow` ライブラリ (画像処理用)
- `tkinter` (標準ライブラリ)

## インストール方法

1. Pythonがインストールされていることを確認してください。
2. 必要なライブラリをインストールします。

```bash
pip install Pillow
```

## 使い方

1. **ツールの起動**:
   ```bash
   python sprite.py
   ```
2. **画像の読み込み**:
   「画像(PNG)を読み込む」ボタンを押し、対象のスプライトシートを選択します。
3. **スプライトの選択**:
   左側の画像内をクリックすると、その位置のスプライト番号が取得され、右側のプレビューに表示されます。
4. **データの登録**:
   - 「サイズ設定」で切り出しサイズを確認（必要に応じて変更）。
   - 「キャラ名」と「状態」を入力または選択。
   - 「リストに登録/更新」をクリックしてリストに追加します。
5. **保存**:
   メニューの「ファイル」>「データをエクスポート (JSON)」から、現在のリストを保存します。

## JSON 出力例

登録されたデータは以下のような形式で保存されます。

```json
{
    "0": {
        "name": "キャラ(チビ)",
        "state": "右",
        "size": "16x16"
    },
    "1": {
        "name": "キャラ(チビ)",
        "state": "左",
        "size": "16x16"
    }
}
```
